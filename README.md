# Practical Basketball Discord Rich Presence

Custom Discord Rich Presence script for Practical Basketball made in Python.

## Setup

1. Make sure you have Python installed and install `pypresence`:
```bash
pip install pypresence
```

2. Go to the [Discord Developer Portal](https://discord.com) and create a **New Application**.
3. Name it `PRACTICAL BASKETBALL DEMON` (this shows up as the game title on Discord) and copy the **Application ID**.
4. Go to **Rich Presence > Art Assets** and upload your custom image.
5. Open `pbpresence.py` and paste your **Application ID** into the `client_id` variable.
6. Run `start.bat`.
